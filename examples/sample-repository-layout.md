# Sample Repository Layout

Every Yggdrasil Labs Engineering repository follows a common structure.

```text
repository/

README.md
LICENSE
CHANGELOG.md
CONTRIBUTING.md
.gitignore

docs/
│
├── architecture/
│     architecture.md
│
├── diagrams/
│     architecture.drawio
│     subsystem-flow.drawio
│
├── images/
│     hero-banner.png
│
└── api/

decisions/
│
├── adr-001.md
├── adr-002.md

roadmap/
│
└── roadmap.md

src/

tests/

scripts/
```

---

## Purpose

### README.md

Project overview and onboarding.

---

### docs/

Contains project documentation.

---

### architecture/

High-level design documents.

---

### diagrams/

Visual representations of system architecture.

---

### images/

Hero banners, screenshots, logos.

---

### decisions/

Architecture Decision Records (ADRs).

---

### roadmap/

Current and future development plans.

---

### src/

Application source code.

---

### tests/

Unit, integration, and end-to-end tests.

---

### scripts/

Automation and utility scripts.

---

This structure provides consistency across every Yggdrasil Labs Engineering project.

Consistency improves maintainability.

Maintainability improves engineering.

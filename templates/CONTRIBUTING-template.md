# Contributing

Thank you for contributing to Yggdrasil Labs Engineering.

---

## Before You Begin

Read the Engineering Handbook.

---

## Engineering Expectations

- Keep components modular.
- Write readable code.
- Document major decisions.
- Add or update tests.
- Update documentation when appropriate.

---

## Pull Requests

Every pull request should:

- Solve a meaningful problem.
- Keep the design simple.
- Follow repository standards.
- Pass applicable tests.
- Improve the project.

---

## The Yggdrasil Test

Before submitting ask:

- Does this make someone's job easier?
- Does it solve a meaningful problem?
- Is it simple and modular?
- Is it documented?
- Does it provide Wisdom Before Action?
